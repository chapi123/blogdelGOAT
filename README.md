## Portfolio y Blog Personal Chaparro

Este proyecto es mi portfolio personal donde exhibo mis trabajos realizados a lo largo del tiempo. Además, se puede encontrar mi blog personal, donde puedo subir avances de trabajos o de mi vida personal, divididos en diferentes tags.

Para correr este proyecto, es necesario primero descargar las librerías necesarias, ubicadas en requirements.txt, con el comando pip install -r requirements.txt en la terminal de este proyecto. Luego, con python manage.py runserver, se inicia el servidor y te muestra el enlace para poder verlo.
