## Bitácora del Trabajo

Para hacer el trabajo, inicié de una manera que resultó poco práctica: arrancó por la parte del blog, sin enlazarla al portfolio. Seguí el tutorial dado por el profesor para lograr una base de datos de posts con contenido, título, fecha de creación, última modificación y slug.

Luego, continué con el índice en donde se verían todos los posts, pero ahora tenía que hacer otra página para que se viera solo el post clickeado. Mi siguiente paso fue este y fue bastante sencillo. Una vez hecho eso, tenía que agregar comentarios; para ello, seguí el tutorial del profesor, pero aquí no me gustaba cómo lo hacía. Lo copié, pero cambié cosas porque me parecía que el usuario no debía escribir su nombre; entonces no agregué el parámetro name en el formulario, lo agregaba luego con un login que haría más tarde.

Hice todo el tutorial restante de los comentarios y resulté con un sistema en el que comentaban el admin o anónimos. Hice el estilo de eso y, ahora, tocaba hacer el login; sin embargo, preferí hacer lo de los tags. Seguí un tutorial y pregunté demasiado a la IA para poder hacer un sistema de tags funcional para categorizar y filtrar los posts. Después agregué el orden, que fue fácil, y hice el CSS de todo.

Ahora no quedaba excusa y tenía que hacer el login. Seguí un tutorial y hice un login que no entiendo cómo funciona, pero se puede iniciar sesión como admin desde ahí; no era mi intención, pero pasó. Ahora los usuarios pueden hacer clic en login y los lleva a una página donde pueden poner nombre y contraseña; si el usuario existe y la contraseña es correcta, inicia sesión; si no, se crea una nueva cuenta. Para verificar que todo anduviera, hice que la IA creara tests y los probara ella misma. Todo dio bien y, ahí mismo, hice el CSS de todo y terminé.

Voy a destacar un error del trabajo que necesitaría cambiar muchas líneas para hacerlo: está mal modularizado, no hay un layout que pueda estar en todas las páginas, pero sí un styles que no hice. Hacerlo ahora significaría borrar muchas líneas y editar bastantes.

Me gustó el resultado; creo que cumple con todo lo pedido y más, pero existe este error mencionado.

Ahora, previo a entregar, voy a hacer unos posts nuevos que estén presentables.
